# Nicolas Kraide

**Building the bridge between AI agents and the physical world.**

Software agents are learning to think. The next step is giving them bodies —
sensors to perceive, actuators to act, and the infrastructure to do it reliably at scale.
That's what I work on.

---

### Focus

- **Agents** — autonomous systems that plan, use tools, and get real work done
- **Physical AI** — robots and embedded devices driven by vision and language models
- **IoT** — edge hardware (ESP32, sensors, controllers) as the nervous system for agents
- **Computer vision** — real-time perception: hands, gestures, objects, people
